# eOceanic Cork data

Data for the 91 locations on the [eOceanic Cork harbours page](https://eoceanic.com/sailing/harbours/europe/ireland/cork/), collected by following each location's "get full information" link (for example [Youghal](https://eoceanic.com/sailing/harbours/europe/ireland/cork/31/youghal)). I'll use it to cross-reference against my shore diving list in [`../Takeout/Cork_Shore_Diving.csv`](../Takeout/Cork_Shore_Diving.csv).

eOceanic is written for boats. Depths are at the anchorage at low water springs, and the access ratings describe approaching by sea. They say nothing about diving, parking or getting in and out of the water on foot. See [Limits of the eOceanic data](../README.md#limits-of-the-eoceanic-data).

## Files

| File | What it is |
|---|---|
| [`eoceanic_cork_sites.json`](eoceanic_cork_sites.json) | Everything extracted, one object per location, in the index page's order |
| [`eoceanic_cork_sites.csv`](eoceanic_cork_sites.csv) | The short fields only, for a spreadsheet |
| [`Locations.md`](Locations.md) | Table of all 91 locations with links, coordinates and ratings, in eOceanic's order and grouped by [zone](#zones). Generated by the extract script |
| [`scripts/fetch_eoceanic.py`](scripts/fetch_eoceanic.py) | Downloads the index page and all 91 location pages into `raw/` |
| [`scripts/extract_eoceanic.py`](scripts/extract_eoceanic.py) | Reads `raw/` and writes the JSON, CSV and `Locations.md` above |
| [`raw/index.html`](raw/index.html), [`raw/links.txt`](raw/links.txt) | The saved index page, and the 91 relative links found on it |
| [`raw/pages/`](raw/pages) | The raw HTML of each location page, named `<id>_<slug>.html` |

To refresh the data, run `python3 scripts/fetch_eoceanic.py` and then `python3 scripts/extract_eoceanic.py`. The scripts find their folders relative to their own location, so they work from any directory. The fetch script waits a second between requests and skips pages it already has, so delete `raw/pages/` (or a single file) to re-download. The extract script makes no network requests.

## Order

Every file lists the locations in the order of eOceanic's index page, and `no` in the data is that position. The page follows the coast clockwise, starting at Youghal (7.84°W) in the east and ending at Ardgroom Harbour (9.88°W) on the Beara Peninsula, so the list runs roughly east to west.

It is not sorted by longitude. In 23 of the 90 steps the next location is slightly further east, because the list follows the shoreline and doubles back where the coast does. Most of these are small moves within one harbour or bay. The larger ones are:

- Cork City Marina (8.46°W) to Glenbrook (8.33°W), up and back down Cork Harbour.
- Ballynatra Cove (9.76°W) to Bantry Harbour (9.46°W), coming out of Dunmanus Bay and into Bantry Bay.
- Ballycrovane Harbour (9.95°W) to Ardgroom Harbour (9.88°W), turning up the Kenmare River.

If you want a strict east to west order, sort on `longitude` (descending, since west is more negative).

## Zones

[`Locations.md`](Locations.md) groups the locations into six zones, and the `zone` field in the data has the same name. The zones are my own grouping, not eOceanic's, which has none. The names are the ones I used earlier for the Google Maps list, plus one for East Cork and Cork Harbour, which that list doesn't cover.

| Zone | Locations | Sites | From | To |
|---|---|---|---|---|
| East Cork & Cork Harbour | 1-15 | 15 | Youghal | Crosshaven |
| Kinsale & South Cork Coast | 16-23 | 8 | Ringabella Bay | Holeopen Bay West |
| Rosscarbery, Galley Head & Seven Heads | 24-40 | 17 | Coolmain Bay | Castlehaven (Castletownshend) |
| Mizen, Roaringwater Bay & Skibbereen | 41-72 | 32 | Barloge Creek (Lough Hyne) | Crookhaven |
| Sheep's Head & Dunmanus Bay | 73-79 | 7 | Dunmanus Harbour | Ballynatra (Trá Ruaim) Cove |
| Beara Peninsula & Bantry Bay | 80-91 | 12 | Bantry Harbour | Ardgroom Harbour |

How the zones are drawn:

- Each zone is one unbroken stretch of eOceanic's list, so it follows the coast and not longitude. That keeps places on the same bay together, such as the Ilen River and Roaringwater Bay sites.
- Where one zone ends and the next begins is a judgement call. For example, I put Coolmain Bay and Courtmacsherry in the Rosscarbery zone because the zone's other sites are on Courtmacsherry and Clonakilty Bays, and Bantry Harbour and Glengarriff in the Beara zone.
- They are geographic only. They say nothing about swell, shelter or dive conditions, and I haven't checked them against the Takeout list.
- They are not the 4 drive-time zones on the map in the [parent README](../README.md#zones).
- The zone boundaries are set in the `ZONES` list in `scripts/extract_eoceanic.py`. Change them there and re-run the script.

## Fields

The `.csv` has the first group below, and the `.json` has all of them.

| Field | Meaning |
|---|---|
| `no`, `zone`, `id`, `name`, `url` | Position in the index page, my [zone](#zones) for it, eOceanic's location id, the name as listed, and the detail page URL |
| `latitude`, `longitude` | Decimal degrees, from the map link on the detail page |
| `position_dm`, `position_note` | The haven position as printed (degrees and decimal minutes) and eOceanic's note on what it marks, such as "Off the town basin beside the Town Hall" |
| `shelter_stars`, `shelter` | eOceanic's shelter rating: 5 Complete protection, 4 Good, 3 Tolerable, 2 Exposed, 1 Stay-aboard |
| `approaches_stars`, `approaches` | eOceanic's approach rating: 5 Safe access, 4 Straightforward, 3 Attentive navigation, 2 Careful navigation, 1 Highly involved navigation |
| `min_depth_m` | "Minimum depth" in metres, which is the figure the index page calls LWS |
| `last_modified`, `contact` | Date eOceanic last changed the entry, and any harbourmaster or mooring phone numbers and VHF channel |
| `overview`, `facilities_text`, `security` | The first overview paragraph, the "What facilities are available?" text and the "Any security concerns?" text |
| `summary`, `initial_fix` | eOceanic's one-line summary and the initial fix waypoint text (JSON only) |
| `how_to_get_in`, `why_visit` | The full sections of that name, which include image captions and credits (JSON only) |
| `facilities_symbols`, `nature_symbols`, `considerations_symbols` | The icon descriptions on the page, such as "Jetty or a structure to assist landing" (JSON only) |
| `thanks_to`, `nearest_havens` | The contributor credit, and the ten nearest havens with distance in nautical miles and bearing (JSON only) |

Some fields are legitimately empty. `contact` is blank for 66 locations and `considerations_symbols` for 43, because those pages list none. The text fields are plain text pulled from HTML, so image captions such as "Image: Burke Corbett" appear inline in `how_to_get_in` and `why_visit`.

## Cross-referencing

The Takeout CSV has Google Maps place names and some bare coordinates. Matching by name will miss the coordinate-only rows, so match those using `latitude` and `longitude` here. The positions are eOceanic's haven position: for an anchorage, the spot where a boat anchors, and for a harbour, usually the seaward end of its main pier. Either can be some distance from the pier or slip a diver would use, so check `position_note` and the map.
